# MyRadar

Welcome to the MyRadar organization on GitHub.

## Purpose

This organization was established primarily to provide GitHub authentication for MyRadar, allowing users to sign in to MyRadar services with their GitHub account.

As a secondary purpose, it is the home for MyRadar's public repositories, including SDK code samples, examples and walkthroughs.
