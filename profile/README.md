# MyRadar

Code samples, SDKs and walkthroughs for adding MyRadar weather to your apps.

## Start here: sample apps

**[MyRadar-SDK-Samples](https://github.com/MyRadar/MyRadar-SDK-Samples)** has complete, runnable sample apps for each MyRadar SDK. Each one is a flight tracker over the MyRadar weather map, with animated radar, warnings, lightning, hurricanes and wind. Each sample uses its SDK exactly as your app would: from the public package, with your own API key.

| Platform | Sample | Walkthrough |
|---|---|---|
| iOS (SwiftUI) | [`ios-demo`](https://github.com/MyRadar/MyRadar-SDK-Samples/tree/main/ios-demo) | [Build a flight tracker (iOS)](https://myradar.com/apidocs/ios-flight-tracker) |
| Android (Jetpack Compose) | [`android-demo`](https://github.com/MyRadar/MyRadar-SDK-Samples/tree/main/android-demo) | [Build a flight tracker (Android)](https://myradar.com/apidocs/android-flight-tracker) |
| Web (Mapbox GL JS) | [`web-demo`](https://github.com/MyRadar/MyRadar-SDK-Samples/tree/main/web-demo) | [Run the sample app (web)](https://myradar.com/apidocs/web-sdk-overview#run-the-sample-app) |

## SDK packages

| SDK | Install from |
|---|---|
| iOS | [MyRadar-iOS-SDK-SPM](https://github.com/MyRadar/MyRadar-iOS-SDK-SPM) (Swift Package Manager) |
| Android | [MyRadar-Android-SDK-Maven](https://github.com/MyRadar/MyRadar-Android-SDK-Maven) (Maven) |
| Web | `@myradar/mapbox` and `@myradar/controls` on npm |

## Weather API tutorials

**[myradar-api-example](https://github.com/MyRadar/myradar-api-example)** shows how to call the MyRadar Weather API directly, with Python tutorials for point forecasts, route forecasts and historical data.

## Get an API key

Every sample and SDK needs a MyRadar API key from the [developer portal](https://myradar.com/developer_portal).
